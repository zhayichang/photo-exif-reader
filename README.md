# EXIF 信息读取工具

一个在浏览器本地读取、整理并可视化照片元数据的静态网页。拖入照片后，即可查看拍摄参数、设备信息、GPS、版权与后期记录，并在公开分享前检查可能暴露隐私的字段。

无需安装、无需后端，也不会将照片上传到服务器。项目可以直接部署到 GitHub Pages。

## 功能亮点

- **完整元数据读取**：解析 EXIF、XMP、IPTC、ICC、JFIF、IHDR 等常见元数据分组。
- **拍摄信息概览**：集中展示相机、镜头、时间、尺寸、光圈、快门、ISO、曝光补偿、焦段和白平衡。
- **后期记录解读**：在文件包含相关字段时，展示 Lightroom / Camera Raw 调整、裁切、几何、色调曲线、HSL 与编辑时间线。
- **画面可视化**：从可解码的图片像素生成 RGB 直方图与主色板。
- **隐私发布检查**：提示 GPS 坐标、设备序列号、作者或版权信息，以及 XMP / Photoshop 编辑记录。
- **信息检索**：支持按关键词搜索全部标签，并按元数据分组筛选。
- **自适应界面**：支持桌面端与移动端，并跟随系统切换浅色或深色主题。

## 隐私说明

照片通过浏览器的文件接口读取，解析、预览和像素分析均在当前设备上完成。项目没有后端服务，不会主动上传、保存或发送照片，也不依赖外部 CDN。

> 页面给出的“隐私提示”是基于已成功解析字段的辅助检查，不等同于专业的元数据清除或隐私审计。公开发布照片前，仍建议使用可信工具移除不需要的元数据。

## 支持范围

| 格式 | 元数据读取 | 图片预览与像素分析 |
| --- | --- | --- |
| JPEG / JPG | 支持 | 支持 |
| TIFF / TIF | 支持 | 取决于浏览器解码能力 |
| PNG | 支持 | 支持 |
| HEIC / HEIF | 支持读取可识别的元数据 | 取决于浏览器与系统解码能力 |
| AVIF | 支持读取可识别的元数据 | 取决于浏览器解码能力 |

当前不支持 CR2、CR3、NEF、ARW、DNG 等 RAW 格式。不同设备与软件写入的标签可能不同；某类信息不存在或无法解析时，对应模块会自动隐藏，不影响其他可用结果。


## 使用方法

1. 将一张受支持的照片拖入上传区域，或点击选择文件。
2. 查看拍摄概览、照片数字指纹、后期记录和隐私提示。
3. 在“全部元数据”中搜索标签或按分组筛选。
4. 点击“选择另一张”继续读取其他照片。

当前一次处理一个文件。

## 实现说明

- 使用原生 HTML、CSS 和 JavaScript，不依赖框架或构建工具。
- 使用本地打包的 [exifr](https://github.com/MikeKovarik/exifr) 7.1.3 解析元数据。
- 使用 Canvas API 生成 RGB 直方图并提取主色。
- 使用 Blob URL 完成本地预览与内置缩略图展示。

## 已知限制

- 浏览器能读取文件中的元数据，不代表它一定能解码并预览该图片；HEIC、HEIF、AVIF 和部分 TIFF 文件尤其受浏览器与操作系统影响。
- 隐私检查只覆盖当前代码识别的常见字段，不能保证发现所有厂商私有标签或嵌入数据。
- 该工具只读取和展示信息，不会修改文件，也不会移除元数据。
- 超大图片的像素分析可能占用较多内存，并受浏览器性能限制。
