# EXIF 信息读取工具

一个隐私优先的照片元数据查看器。把照片拖入浏览器，即可查看拍摄参数、设备信息、定位数据、版权字段与后期记录，并在公开分享前快速识别可能暴露隐私的信息。

整个处理过程在浏览器本地完成：无需安装、无需后端，照片不会被上传、保存或发送到服务器。

## 功能概览

- **读取常见元数据**：解析 EXIF、XMP、IPTC、ICC、JFIF、IHDR 等分组，并保留完整标签供检索。
- **整理摄影信息**：集中展示相机、镜头、拍摄时间、图像尺寸、光圈、快门、ISO、曝光补偿、焦段和白平衡。
- **解读后期记录**：在文件包含相关字段时，展示 Lightroom / Camera Raw 调整、裁切与几何、色调曲线、HSL 以及编辑时间线。
- **生成画面分析**：从浏览器可解码的图片像素生成 RGB 直方图和主色板。
- **辅助隐私检查**：提示 GPS 坐标、设备序列号、作者或版权信息，以及 XMP / Photoshop 编辑记录；序列号默认遮罩显示。
- **浏览完整数据**：支持按关键词搜索全部标签，并按元数据分组筛选。
- **适配不同设备**：支持桌面端和移动端，并跟随系统切换浅色或深色主题。


## 使用方式

1. 选择一张照片。
2. 查看拍摄概览、照片数字指纹、编辑记录和隐私提示。
3. 在“全部元数据”中搜索标签或按分组筛选。
4. 点击“选择另一张”继续读取其他照片。

当前一次处理一个文件。工具只读取和展示信息，不会修改原文件，也不会移除其中的元数据。

## 隐私与数据处理

应用只加载仓库内的静态资源，照片的解析、预览和像素分析均在当前浏览器标签页中完成：

```text
本地照片 → Browser File API → exifr / Canvas → 页面展示
```

项目没有后端接口，不依赖外部 CDN，也不会主动上传、保存或发送照片。

> “隐私提示”只检查当前代码能够识别且已经成功解析的常见字段，不等同于专业的元数据清除或完整隐私审计。公开发布照片前，请使用可信工具移除不需要的元数据，并检查导出的最终文件。

## 支持范围

| 格式 | 元数据读取 | 图片预览与像素分析 |
| --- | --- | --- |
| JPEG / JPG | 支持 | 支持 |
| TIFF / TIF | 支持 | 取决于浏览器解码能力 |
| PNG | 支持 | 支持 |
| HEIC / HEIF | 支持读取可识别的元数据 | 取决于浏览器与操作系统解码能力 |
| AVIF | 支持读取可识别的元数据 | 取决于浏览器解码能力 |

当前不支持 CR2、CR3、NEF、ARW、DNG 等 RAW 格式。不同设备与软件写入的标签可能不同；某类信息不存在或无法解析时，对应模块会自动隐藏，不影响其他可用结果。

## 结果说明

| 区域 | 内容 |
| --- | --- |
| 照片数字指纹 | RGB 直方图、主色板与元数据分组构成 |
| 核心摄影信息 | 相机、镜头、拍摄时间、尺寸和曝光参数 |
| 信息摘要与隐私提示 | 定位、署名、序列号和编辑记录等发布前检查项 |
| 编辑解读 | Camera Raw / Lightroom 参数、裁切、曲线、HSL 与时间线 |
| 扩展信息 | 拍摄模式、位置、版权、设备、缩略图与字段完整度 |
| 全部元数据 | 可搜索、可按分组筛选的原始标签和值 |

只有在文件中找到相应字段时，相关模块才会显示。

## 技术实现

- 原生 HTML、CSS 和 JavaScript，无框架、无构建工具。
- 使用本地打包的 [exifr](https://github.com/MikeKovarik/exifr) 7.1.3 解析元数据。
- 使用 Canvas API 生成 RGB 直方图并提取主色。
- 使用 Blob URL 完成本地预览和内置缩略图展示。
- 采用响应式布局，并支持系统深色模式。

## 已知限制

- 浏览器能够读取文件中的元数据，不代表一定能够解码并预览该图片；HEIC、HEIF、AVIF 和部分 TIFF 文件尤其受浏览器与操作系统影响。
- 隐私检查无法保证识别所有厂商私有标签、嵌入文件或尚未覆盖的元数据类型。
- 文件没有写入某项信息时，工具无法推断缺失的拍摄参数或编辑记录。
- 超大图片的像素分析可能占用较多内存，并受设备和浏览器性能限制。
- 工具不会清除元数据，也不会生成适合公开分享的副本。
